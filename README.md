# 👑 Royal Threads Couture

![Tech Stack](https://img.shields.io/badge/Tech_Stack-HTML5%20%7C%20Tailwind%20CSS-22d3ee?style=flat-square)
![UI Theme](https://img.shields.io/badge/Theme-Elegance%20%2F%20Luxury-8b2fd6?style=flat-square)

**Royal Threads Couture** is a responsive, elegant front-end eCommerce landing page designed for a premium clothing brand. Built with a focus on timeless elegance and comfort, this project showcases a modern web interface tailored for showcasing high-quality apparel. 

## ✨ Key Features

*   **Responsive Navigation:** Includes a sticky header with smooth hover-underline animations, quick links, and responsive mobile menu toggles alongside shopping bag and user profile icons.
*   **Immersive Hero Section:** Features a full-width background image with a dark overlay and a prominent call-to-action to shop premium shirts, T-shirts, and pants.
*   **Curated Collections:** Dedicated visually appealing category cards for Men's, Women's, and Accessories collections featuring smooth scale-on-hover effects.
*   **Featured Products Grid:** A clean product display grid showcasing items like Oxford formal shirts, silk blouses, and denim jackets, complete with pricing (in ₹) and "Add to Cart" buttons.
*   **Client Testimonials:** A dedicated review section displaying 5-star customer feedback to build brand trust.
*   **Newsletter Integration:** A stylized subscription form inviting users to join the "Royal Circle" for exclusive offers.
*   **Comprehensive Footer:** Includes quick links, customer service information, and social media connectivity (Instagram and Facebook).

## 🛠️ Tech Stack

*   **HTML5:** Semantic markup for structure and accessibility.
*   **Tailwind CSS:** Utilized via CDN for rapid, utility-first styling and responsive design.
*   **Feather Icons:** Lightweight, open-source icons injected via JavaScript for crisp UI elements.
*   **Google Fonts:** Combines 'Playfair Display' for elegant headings and 'Lato' for clean, readable body text.

## 🎨 UI/UX Design Profile

The project features a custom-configured Tailwind theme to reflect a luxurious brand identity:
*   **Coffee (`#340307`):** Deep, rich primary text and header background.
*   **Cream (`#E8DCC2`):** Soft, warm background color for primary sections.
*   **Olive (`#6B705C`):** Used for product card backgrounds and subtle accents.
*   **Stone (`#B7B7A4`):** Utilized for borders, secondary text, and hover states.
*   **Micro-interactions:** Custom CSS classes for sliding underline animations and smooth product card lift/scale effects on hover.
